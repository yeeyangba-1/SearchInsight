# Query 意图分类学习卡片

## 1. 这个模块做什么？

这个模块用简单关键词规则判断用户 query 属于哪类问题，比如售后、价格、账号权限或技术问题。

## 2. 输入是什么？

输入是用户搜索问题 query，例如“企业版多少钱一个月”。

## 3. 输出是什么？

输出是 intent_category，也就是 Query 类型：

- 售后问题
- 价格费用
- 账号权限
- 技术问题
- 产品功能
- 知识咨询
- 其他

## 4. 分类规则是什么？

- 退款、退货、售后、换货 -> 售后问题
- 价格、费用、多少钱、套餐 -> 价格费用
- 登录、账号、密码、权限 -> 账号权限
- 报错、接口、API、部署、无法运行 -> 技术问题
- 功能、怎么用、支持什么 -> 产品功能
- 是什么、为什么、区别 -> 知识咨询
- 没有匹配关键词 -> 其他

## 5. 为什么 Query 分类对 AI 搜索优化有用？

Query 分类可以帮助我们看清楚哪类问题更容易出 Bad Case。比如技术问题经常答非所问，就说明需要优化技术文档召回或回答约束。

## 6. 面试时一句话怎么讲？

这个模块主要解决的是 AI 搜索日志缺少问题类型标签的问题，我用关键词规则先给 query 打上业务分类，方便后续按问题类型分析 Bad Case 分布和优化重点。
