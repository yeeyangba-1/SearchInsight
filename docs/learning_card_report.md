# AI搜索诊断报告学习卡片

## 1. 这个模块做什么？

这个模块把搜索日志统计结果整理成一份简短 Markdown 诊断报告。

## 2. 输入是什么？

输入是 `analyze_search_logs(file_path)` 返回的 summary 字典。

## 3. 输出是什么？

输出是 `outputs/search_diagnosis_report.md`。

## 4. 报告里包含哪些内容？

- 数据概览
- Query 类型分布
- Bad Case 类型分布
- 高风险问题类型
- 典型 Bad Case 示例
- 简单优化建议

## 5. 为什么报告对 AI搜索优化有用？

报告把统计结果翻译成业务可读的诊断结论，方便快速判断主要问题和优化方向。

## 6. 面试时一句话怎么讲？

这个模块主要解决的是 AI 搜索分析结果不够直观的问题，我把统计 summary 自动生成 Markdown 报告，让业务和算法同学都能快速看到主要 Bad Case、风险类型和优化建议。
